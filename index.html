這個網站怎麼做的

每篇筆記都是我請 AI 照著 AGENTS.md 寫的，所以格式才會都一樣。想加新的一篇，在 Claude Code 打這行就好： 

/new-note RAG 入門
1

AGENTS.md

寫給 AI 看的規則：檔案放哪、檔名怎麼取、每篇要有哪些段落、哪些事不能做。

2

templates/note.html

筆記模板，七個段落已經排好，AI 只要把內容填進去。

3

data/notes.json

每篇的標題、分類、日期都記在這裡，首頁的卡片是從這裡讀出來的。

4

check_notes.py

寫完跑一次，少段落、檔名錯、忘記登記都會被挑出來。push 到 GitHub 時也會自動跑。
