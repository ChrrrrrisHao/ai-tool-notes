元件庫

新增或修改筆記時，只能使用這一頁列出的元件。每個元件都附上實際樣子與可直接複製的 HTML（對應 AGENTS.md 第 7、8 節）。

色票與字體

顏色只能用 CSS 變數，頁面與新元件不可直接寫色碼。切換右上角深淺色，可以看到同一組 token 自動換色。

--paper
--card
--ink
--accent
--highlight
--cat-tool
--cat-concept
--cat-skill
--cat-workflow

內文字體 Noto Sans TC；程式碼字體 JetBrains Mono。

分類標籤與難度

工具 概念 技巧 流程

入門 進階 深入

筆記頁的分類與難度由 main.js 依 data/notes.json 自動產生，不要手寫；這裡只是展示樣子。

三個重點 .keypoints

  • 第一個重點，每條 30 字以內。
  • 第二個重點，讀完就知道這篇在講什麼。
  • 第三個重點，剛好三條，不多不少。
<ul class="keypoints">
  <li>第一個重點</li>
  <li>第二個重點</li>
  <li>第三個重點</li>
</ul>

提示框 .callout

補充說明（--note）

放比喻、背景知識或「順帶一提」。

小技巧（--tip）

放能讓讀者少走冤枉路的做法。

注意（--warn）

「常見錯誤」區塊專用。避免：每個都要寫怎麼避免。

<aside class="callout callout--warn">
  <p class="callout__title">錯誤名稱</p>
  <p>為什麼會錯。<strong>避免：</strong>怎麼做才對。</p>
</aside>

步驟 .steps

  1. 安裝工具

    每個步驟的標題以動詞開頭。

  2. 設定專案

    步驟裡可以再放 pre.code。

  3. 確認結果

    最後一步通常是「怎麼確認做對了」。

<ol class="steps">
  <li><strong>安裝工具</strong><p>說明。</p></li>
  <li><strong>設定專案</strong><p>說明。</p></li>
  <li><strong>確認結果</strong><p>說明。</p></li>
</ol>

程式碼與 Prompt .code

python -m http.server 8000
請用白話解釋什麼是 RAG，300 字以內，使用繁體中文。

data-lang 會顯示在左上角，右上角的「複製」按鈕由 main.js 自動加上。程式碼裡的 <、>、& 要寫成 HTML 實體。

<pre class="code" data-lang="bash"><code>指令</code></pre>
<pre class="code code--prompt" data-lang="Prompt"><code>Prompt 內容</code></pre>

小測驗 .quiz

1. 新筆記應該從哪裡開始？

解析：模板已經放好七個固定區塊，從模板開始才能保持一致。

<div class="quiz" data-answer="b">
  <p class="quiz__q">1. 題目？</p>
  <ol class="quiz__options">
    <li><button type="button" data-option="a">選項 A</button></li>
    <li><button type="button" data-option="b">選項 B</button></li>
    <li><button type="button" data-option="c">選項 C</button></li>
  </ol>
  <p class="quiz__explain">解析：……</p>
</div>

延伸閱讀 .refs

  • AGENTS.md 官方網站外部連結會自動加上 ↗。
  • 回到首頁站內連結不用開新分頁。
<ul class="refs">
  <li><a href="https://…" target="_blank" rel="noopener">標題</a><span>一句話說明</span></li>
</ul>
