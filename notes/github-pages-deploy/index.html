用 GitHub Pages 發布網站

免費把靜態網站放上網路，push 完一兩分鐘就上線。

三個重點

  • GitHub Pages 可以免費託管 HTML／CSS／JS 靜態網站。
  • 在 repo 設定選好分支與資料夾，就會產生公開網址。
  • 路徑一律用相對路徑，檔名一律小寫。

是什麼

GitHub Pages 是 GitHub 提供的靜態網站託管服務。只要把網頁檔案放進 GitHub repository、打開設定，GitHub 就會幫你產生一個網址，格式是 https://<帳號>.github.io/<repo 名稱>/。

「靜態」的意思是：伺服器只負責把檔案原封不動傳給瀏覽器，不能執行 PHP、資料庫等後端程式。像本站這樣只有 HTML、CSS、JavaScript 的網站剛好適合。免費帳號的 repo 需要設為公開（Public）才能使用 Pages（截至 2026-11）。

檔案和網址的對應

根目錄的 index.html 對應 /ai-tool-notes/；notes/agents-md-guide/index.html 對應 /ai-tool-notes/notes/agents-md-guide/。資料夾裡放 index.html，網址就可以省略檔名。

怎麼用

  1. 建立公開的 repository

    在 GitHub 按 New repository，設為 Public。也可以用 GitHub CLI 一行完成（見下一節）。

  2. 把網站檔案推上去

    首頁檔名必須是 index.html，放在根目錄。

    git init
git add .
git commit -m "feat: 第一版網站"
git branch -M main
git remote add origin https://github.com/<帳號>/<repo 名稱>.git
git push -u origin main
  3. 開啟 Pages

    進入 repo 的 Settings → Pages，Source 選「Deploy from a branch」，Branch 選 main、資料夾選 / (root)，按 Save。

  4. 等待部署完成

    大約 1–2 分鐘。Actions 分頁會出現 pages build and deployment，完成後 Settings → Pages 最上方會顯示網址。

  5. 加上 .nojekyll

    在根目錄放一個空的 .nojekyll 檔，告訴 GitHub 不要用 Jekyll 處理，避免底線開頭的檔案被忽略。

  6. 之後只要 push 就會更新

    改完檔案、commit、push，網站會自動重新部署。

實際範例

用 GitHub CLI 從建立到上線

# 1. 從目前資料夾建立公開 repo，並把 main 推上去
gh repo create ai-tool-notes --public --source=. --push

# 2. 開啟 Pages：main 分支、根目錄
gh api -X POST repos/<帳號>/ai-tool-notes/pages \
  -f "source[branch]=main" -f "source[path]=/"

# 3. 查看網址與部署狀態
gh api repos/<帳號>/ai-tool-notes/pages

上線前先在本機預覽

python -m http.server 8000
# 開啟 http://localhost:8000

常見錯誤

用了 / 開頭的絕對路徑

本機正常，上線後樣式全部消失。因為網站在 /repo 名稱/ 子路徑下，/assets/style.css 會指到錯的位置。避免：一律用相對路徑，例如 ../../assets/css/style.css。

檔名大小寫不一致

Windows 不分大小寫，GitHub Pages 會分，Logo.PNG 和 logo.png 是兩個不同的檔案。避免：檔名全部用小寫。

直接雙擊 HTML 預覽

用 file:// 開啟時，fetch 讀不到 JSON，頁面看起來是空的。避免：用 python -m http.server 開本機伺服器預覽。

剛 push 完就說沒更新

部署需要時間，瀏覽器也有快取。避免：等一兩分鐘，再按 Ctrl+Shift+R 強制重新整理。

小測驗

1. GitHub Pages 適合放哪一種網站？

解析：GitHub Pages 只傳送檔案，不能執行後端程式。

2. 本機正常、上線後樣式全不見，最可能的原因是？

解析：網站在子路徑下，絕對路徑會指到網域根目錄，找不到檔案。

3. 網站首頁的檔案應該叫什麼？

解析：伺服器預設會找資料夾裡的 index.html 當首頁。
