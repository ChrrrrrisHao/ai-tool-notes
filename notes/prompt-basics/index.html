Prompt 基本功：五個要素

把需求講清楚：背景、任務、限制、格式、範例。

三個重點

  • AI 答得不好，多半是因為需求沒講清楚。
  • 好 Prompt 包含背景、任務、限制、格式、範例。
  • 不確定怎麼寫時，先請 AI 反問你問題。

是什麼

Prompt（提示詞）就是你給 AI 的指令。AI 看不到你的腦袋，只能依照你寫的字推測你要什麼；你沒說的部分，它就會用「最常見的答案」補上，結果通常很普通。

寫 Prompt 不需要咒語或特殊格式。重點是：把一位聰明、但第一天上班的同事需要知道的資訊交代清楚。下面五個要素可以當作檢查清單。

要素回答的問題例子
背景我是誰？用途是什麼？我是大一學生，要做課堂報告
任務要你做什麼？用白話解釋 RAG
限制有什麼條件？300 字內、不要數學公式
格式結果長什麼樣？定義＋比喻＋三點優點
範例有沒有參考？比喻的感覺像這樣：「……」

怎麼用

  1. 先寫任務

    用動詞開頭，一句話說清楚要做什麼：整理、比較、改寫、找錯。

  2. 補上背景

    說明你是誰、用途是什麼、讀者是誰。同一個問題，給教授看和給國中生看，答案完全不同。

  3. 加上限制

    字數、語言、語氣、不能用的東西。例如「使用繁體中文、臺灣用語」。

  4. 指定輸出格式

    條列、表格、JSON 或 Markdown，直接說，或把欄位畫出來。

  5. 給一個範例

    一段「我想要的感覺」的範例，通常比一堆形容詞有效。

  6. 檢查後追問

    第一次不滿意很正常。指出哪裡不對再修改，不用整段重來。

實際範例

改寫前：只有任務

幫我介紹 RAG

改寫後：五個要素都有

【背景】我是資管系大一學生，下週要在課堂上做 3 分鐘報告，聽眾是同學。
【任務】請用白話解釋什麼是 RAG（檢索增強生成）。
【限制】
- 使用繁體中文、臺灣用語
- 300 字以內，不要出現數學公式
- 不確定的地方請直接說不確定
【格式】
1. 一句話定義
2. 一個生活化比喻
3. 三個優點（條列）
【範例】比喻的感覺像這樣：「就像開書考試，先翻課本再作答。」

小技巧：讓 AI 先反問你

需求還很模糊時，在 Prompt 最後加一句：「開始之前，請先問我 3 個你需要知道的問題。」

常見錯誤

只給形容詞

「專業一點」「好看一點」每個人的定義都不同。避免：改成具體條件，例如「用表格比較三個方案，每格 ≤ 15 字」。

一次塞好幾個任務

一長串需求很容易漏做。避免：拆成幾次問，或把需求編號，要求逐項完成並回報。

完全相信輸出

AI 可能寫出看起來正確、其實是錯的內容（俗稱「幻覺」）。避免：重要的事實、數字、引用自己查證，並在 Prompt 裡要求「不確定就說不確定」。

小測驗

1. 「幫我寫一篇文章」最缺少哪些要素？

解析：它只有模糊的任務，不知道寫給誰、寫多長、寫成什麼樣子。

2. 想讓 AI 的結果可以直接貼進 Excel，最該補上哪個要素？

解析：指定「輸出成表格，欄位為……」，結果才能直接貼上使用。

3. AI 的回答看起來很專業，接下來最好？

解析：看起來專業不等於正確，查證是使用 AI 的基本功。
