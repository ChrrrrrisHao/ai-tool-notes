Claude Code 入門

在終端機裡和 AI 一起讀程式、改檔案、跑指令。

三個重點

  • Claude Code 是能直接讀寫檔案、執行指令的 AI 程式助理。
  • 交代任務時講清楚「目標、範圍、完成條件」。
  • 用 CLAUDE.md 讓它記住專案規則，不用每次重講。

是什麼

Claude Code 是 Anthropic 推出的 AI 程式開發工具。和在網頁聊天視窗貼程式碼不同，它直接在你的專案資料夾裡工作：可以搜尋與閱讀整個專案、一次修改多個檔案、執行測試或指令，再依結果繼續修正。

它可以在終端機（CLI）使用，也有桌面 App、網頁版，以及 VS Code、JetBrains 等編輯器外掛（截至 2026-11）。使用前需要登入 Claude 訂閱帳號，或使用 Anthropic API 金鑰。

比喻一下

把它想成一位坐在你電腦前的實習工程師：手腳很快、會自己翻資料，但每次要改檔案或跑指令之前，都會先問你可不可以。

比較網頁聊天機器人Claude Code
看得到什麼你貼上的片段整個專案資料夾
修改檔案你自己複製貼上直接編輯，並顯示改了哪裡
執行指令不行可以，執行前先詢問
記住專案規則每次重講自動讀取 CLAUDE.md

怎麼用

  1. 安裝 Claude Code

    依官方文件安裝。Windows 在 PowerShell 執行第一行；macOS／Linux 在終端機執行第二行。

    irm https://claude.ai/install.ps1 | iex
    curl -fsSL https://claude.ai/install.sh | bash
  2. 進入專案資料夾並啟動

    它只會在你啟動的資料夾裡工作，所以先 cd 到專案，再輸入 claude。第一次啟動會打開瀏覽器請你登入。

  3. 產生 CLAUDE.md

    輸入 /init，它會掃描專案並寫出一份專案說明。之後每次啟動都會自動讀取這份檔案。

  4. 用自然語言交代任務

    講清楚要做什麼、只能改哪些檔案、怎樣才算完成。範例見下一節。

  5. 審核每一個變更

    它要改檔或執行指令時會先詢問，看清楚再同意。想停下來就按 Esc。

  6. 切換模式與清空對話

    按 Shift+Tab（部分 Windows 環境是 Alt+M）可切換權限模式，例如先用 Plan 模式討論計畫再動手；一件事做完就用 /clear 開始下一件。

實際範例

一個好的任務描述

請在 index.html 的頁尾加上「回到頂端」按鈕：
- 只修改 index.html 與 assets/css/style.css
- 樣式沿用現有的 .chip 元件，不要新增顏色
- 完成後告訴我改了哪些地方，以及要怎麼在瀏覽器確認

常用指令速查

claude                        # 在目前資料夾啟動
claude "解釋這個專案的結構"     # 帶著第一個問題啟動
claude -c                     # 接續上一次的對話
/init                         # 產生 CLAUDE.md
/clear                        # 清空對話，開始新任務
/compact                      # 壓縮對話，只保留重點
/help                         # 查看所有指令

常見錯誤

任務講得太模糊

「幫我把網站變好看」只能讓它用猜的。避免：寫出具體目標、可以改的範圍和完成條件，像上面的範例一樣。

沒看變更就全部同意

它可能改到你沒預期的檔案。避免：同意前先看改了哪裡；動手前先 git commit 一次，出錯時可以還原。

一個對話塞太多不相關的事

對話越長、主題越雜，回答品質越差。避免：一件事做完就 /clear，再開始下一件。

把密碼或 API 金鑰貼進對話

機密資訊可能被寫進檔案、甚至被 commit。避免：機密放在 .env 並加入 .gitignore，只告訴 AI「金鑰在環境變數裡」。

小測驗

1. Claude Code 和一般網頁聊天機器人最大的差別是？

解析：它在你的專案資料夾裡工作，能看整個專案、改檔案、跑指令，這是和聊天視窗最大的不同。

2. 想讓它每次都記得「這個專案用繁體中文、不准用框架」，最好的做法是？

解析：CLAUDE.md 會在每次啟動時自動載入，寫一次就一直有效。

3. 做完一個任務、要開始完全不相關的下一件事，建議先？

解析：清空對話可以避免前一個任務的內容干擾新任務。
