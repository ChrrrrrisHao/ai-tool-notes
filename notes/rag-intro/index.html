RAG 入門

先查資料再回答，讓 AI 少說錯話。

三個重點

  • RAG 是先找資料、再讓 AI 根據資料回答的做法。
  • 能讓 AI 回答它沒學過的內容，例如你的講義。
  • 好不好用，關鍵在資料切得好、找得準。

是什麼

RAG 是 Retrieval-Augmented Generation 的縮寫，中文常翻成「檢索增強生成」。大型語言模型只知道訓練時看過的資料，不知道你的課堂講義、公司文件，也不知道訓練之後發生的事。直接問它，它可能會用猜的，猜錯了還講得很有自信。

RAG 的做法是：收到問題後，先去你準備好的資料裡找出最相關的幾段，把這幾段和問題一起放進 Prompt，再請模型根據這些資料回答。模型本身沒有改變，只是每次回答前多看了「小抄」。

比喻一下

直接問模型像閉書考試，只能靠記憶；RAG 像開書考試，先翻到相關的那幾頁，再照著課本作答。

比較直接問RAG微調（Fine-tuning）
能用自己的資料嗎不行可以，換資料就好可以，但要重新訓練
資料更新無法改資料庫就生效要再訓練一次
能附出處嗎很難可以標出用了哪一段很難
上手難度最低中等最高

怎麼用

  1. 準備資料

    收集要讓 AI 參考的文件，例如講義、PDF、筆記，先整理成純文字。

  2. 切成小段

    把長文件切成一段一段（chunk）。一段太長會混進太多主題，太短又會缺上下文，通常從幾百字一段開始試。

  3. 轉成向量存起來

    用 Embedding 模型把每一段轉成一串數字（向量），存進向量資料庫。意思越接近的文字，向量也越接近。

  4. 找出相關段落

    使用者發問時，把問題也轉成向量，找出距離最近的幾段。

  5. 放進 Prompt 再回答

    把找到的段落和問題一起交給模型，要求它只根據這些資料回答，並標出用了哪一段。

實際範例

迷你 RAG：看懂流程就好

下面用「共同字數」代替向量相似度，只用 Python 內建功能，複製就能執行。真正的系統會換成 Embedding 模型和向量資料庫，但流程一樣。

# 迷你 RAG 示意：用「共同字數」代替向量相似度
docs = {
    "講義第 1 章": "RAG 會先檢索相關文件，再把文件內容放進提示詞，讓模型根據內容回答。",
    "講義第 2 章": "Embedding 會把文字轉成向量，意思越接近的句子，向量距離越近。",
    "講義第 3 章": "GitHub Pages 可以免費託管靜態網站。",
}

def score(question, text):
    return sum(1 for ch in set(question) if ch.strip() and ch in text)

question = "RAG 是怎麼回答問題的？"

# 1. 檢索：找出最相關的兩段
top = sorted(docs.items(), key=lambda kv: score(question, kv[1]), reverse=True)[:2]

# 2. 組合 Prompt：把找到的段落和問題放在一起
context = "\n".join(f"[{name}] {text}" for name, text in top)
prompt = f"""請只根據下面的資料回答，並標出引用的章節；資料裡沒有的就說不知道。

{context}

問題：{question}"""

print(prompt)  # 3. 把這段 prompt 交給 LLM

最後交給模型的 Prompt 長這樣

請只根據下面的資料回答，並標出引用的章節；資料裡沒有的就說不知道。

[講義第 1 章] RAG 會先檢索相關文件，再把文件內容放進提示詞，讓模型根據內容回答。
[講義第 2 章] Embedding 會把文字轉成向量，意思越接近的句子，向量距離越近。

問題：RAG 是怎麼回答問題的？

常見錯誤

資料切得太大或太小

一段太大，找出來的內容很雜；太小，句子被切斷、意思不完整。可以先用幾百字一段、前後重疊一兩句的方式試，再看回答品質調整。

找錯段落，AI 還是照答

檢索不準的時候，模型會拿不相關的資料硬湊答案。Prompt 裡要寫「資料沒有就說不知道」，再請它標出處，方便你回頭核對。

以為用了 RAG 就不會錯

資料本身寫錯或過期，答案一樣會錯。資料要定期更新，重要的答案還是要回去看原文。

小測驗

1. RAG 的 R（Retrieval）指的是什麼？

解析：Retrieval 是「檢索」，也就是回答前先去資料裡找相關內容。

2. 想讓 AI 回答這學期講義的內容，比較適合哪種做法？

解析：模型沒看過你的講義，換再大的模型也一樣；把講義當資料來源才找得到答案。

3. 為什麼 Prompt 裡要寫「資料沒有就說不知道」？

解析：沒有這句話，模型找不到資料時常會用猜的，而且看起來很像真的。
